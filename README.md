# RA/BELA GAMING website
Static website for GitHub Pages. Upload the contents of this ZIP to the root of `RAGaming64/ragaming64.github.io`, then enable Pages from `main` / root.

This first version uses a text brand mark. Replace it with the original logo when available. Bela's profile links and additional content are placeholders. GitHub Pages is static hosting, so this version does not include a secure private admin dashboard; updates are made by editing repository files.
